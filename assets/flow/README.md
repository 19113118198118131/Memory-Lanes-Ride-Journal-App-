# Memory Lanes Flow Assets

Flow uses a hybrid asset system designed for a static, offline-first PWA:

- `flow-assets.js` defines colour, sky, surface, motorcycle, prop, particle, and quality presets.
- `flow-effects.js` generates deterministic mountains and pooled particles.
- `flow-renderer.js` draws the cinematic road, lighting, reflections, props, and motorcycles at runtime.
- The SVG libraries below provide reusable original silhouettes and interface symbols without third-party branding.

All artwork is original to Memory Lanes. Runtime effects are resolution independent and do not require a network connection.
